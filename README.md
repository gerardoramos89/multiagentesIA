# MultiagentesIA

## Introducción

Bienvenido al proyecto MultiagentesIA. Este proyecto tiene como objetivo desarrollar una plataforma multiagente para gestionar la Inteligencia Artificial, con un equipo de agentes que sigan reglas Scrum para ser autónomos y codificados, y crear todo lo que un ciclo de desarrollo de software requiera.

## Objetivo

El objetivo principal de este proyecto es desarrollar una plataforma multiagente que permita la gestión de proyectos de Inteligencia Artificial de manera eficiente y organizada, utilizando un equipo de agentes autónomos que sigan las reglas y procesos Scrum.

## Alcance

El alcance del proyecto incluye:
- Desarrollo de una plataforma multiagente.
- Implementación de agentes autónomos con reglas Scrum.
- Automatización de ciclos de desarrollo de software.
